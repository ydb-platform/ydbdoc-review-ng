# Классификация изменений языковых пар, 2026-10-28

## Согласованная задача

Работа только в main ydb-platform/ydbdoc-review-ng. Пользователь разрешил push,
перемещение используемого CI тега v1.0.1 и повторный запуск doc_translate на
PR ydb-platform/ydb#52478. Новые ветки не создавать. Существовавшие локальные
правки лимита из предыдущего исследования входят в эту работу.

Источник проблемы: PR #52478 меняет один абзац RU и EN согласованно. Старый
классификатор отправляет before/after обоих файлов и обе текущие версии ещё
раз через pairs. Это 253473 байта запроса и 48097 фактических входных токенов.
Значение max_tokens=795103 отвергается API, максимум генерации 262144.
При повторе с max_tokens=4096 получен HTTP 200 и 90 выходных токенов, однако
модель ошибочно потребовала перевод. Старое автоматическое пропускание любой
пары с двумя изменёнными файлами также неверно: перевод может быть частичным.

Число 185445 токенов из первой локальной проверки ошибочно: бинарное поле
String аудита было неверно декодировано через json-unicode CLI. Для повтора
восстановлен UTF-8. Не использовать это число как размер исходного CI запроса.

## Новый контракт

- Классифицировать каждую Markdown-пару отдельно.
- Передавать diff, целые затронутые блоки и заголовки. Не дублировать after.
- Согласованные изменения обеих локалей -> no_translation.
- Только недостающие изменения -> ru_to_en либо en_to_ru для конкретной пары.
- need_context -> ограниченное расширение контекста целыми разделами.
- conflict / недостаточный контекст -> checkpoint с причиной для конкретной
  пары; не выбирать исходный язык произвольно и не обрезать данные молча.
- Новые страницы без target переводятся полностью в пределах лимитов.
- Git delete/rename и ресурсы остаются ответственностью Python.
- Классификатор не задаёт произвольные операции над файлами.
- Одна публикация может содержать независимые пары разных направлений.
- Согласованные пары не вызывают translator и не создают пустой PR.
- Решения пар сохраняются для continue, не схлопываются в общее направление.
- Ограничение ответа модели отдельно от окна контекста; direction <=4096.
